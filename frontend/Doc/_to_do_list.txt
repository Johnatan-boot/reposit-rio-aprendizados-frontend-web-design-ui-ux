# Agora o projeto muda de nível

Até aqui estávamos trabalhando principalmente na **Home**.

A partir daqui, a lógica passa a ser:

```text
             CASA DE TINTAS
                    │
          ┌─────────┴─────────┐
          │                   │
       DESIGN              UX/UI
       SYSTEM              SYSTEM
          │                   │
     ┌────┴────┐        ┌─────┴─────┐
     │         │        │           │
   Tokens   Components  States   Accessibility
     │         │        │           │
     └─────────┴────────┴───────────┘
                    │
                    ▼
              NOVAS PÁGINAS

              sem reinventar o CSS a cada página.

Esse é exatamente o tipo de evolução que vale mostrar em portfólio: você começou com HTML/CSS, passou por semântica e acessibilidade e agora está demonstrando pensamento de Design System e consistência de produto.
