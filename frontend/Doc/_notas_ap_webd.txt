"A interface comunica isso de maneira clara, bonita e consistente?"

2. O que um Web Designer avalia?

Quando você olha para uma tela, quero que comece a enxergar problemas e decisões de design.

Hierarquia visual

Pergunte:

O que eu quero que o usuário veja primeiro?

Depois:

O que ele deve perceber em segundo lugar?

Depois:

O que é informação secundária?

Exemplo:

              CONTROLE DE QUALIDADE


        1. ────────  TITULO


        2. ────────  MÉTRICAS




        3. ────────  FILTROS




        4. ────────  CONTEÚDO PRINCIPAL

Se tudo possui o mesmo peso visual, nada possui hierarquia.

3. Os princípios que você precisa dominar

Eu quero que você aprenda estes como fundamentos da profissão.

01 — Hierarquia

Determinar o que chama atenção primeiro.

02 — Contraste

Diferenças de:

cor
tamanho
peso
espaço
forma
posição
03 — Alinhamento

Elementos devem parecer pertencer ao mesmo sistema.

04 — Proximidade

Coisas relacionadas ficam próximas.

05 — Repetição

Componentes semelhantes precisam parecer semelhantes.

06 — Espaço negativo

Não tenha medo do espaço vazio.

Espaço vazio também é design.

07 — Consistência

Se um botão verde significa "confirmar", ele não deveria virar vermelho em outra tela sem motivo.

08 — Legibilidade

O usuário precisa conseguir ler sem esforço.

09 — Acessibilidade

Uma interface bonita que não pode ser utilizada por parte dos usuários é uma interface incompleta.

10 — Affordance

O elemento precisa comunicar como deve ser utilizado.

Um botão precisa parecer botão.

5. A regra 60 / 30 / 10

Uma técnica interessante para começar:

60%
Base


30%
Superfícies / elementos secundários


10%
Destaques

Não significa que você precisa obedecer matematicamente.

É uma forma de evitar que a interface fique visualmente "barulhenta".

6. Tipografia

Outro erro muito comum de quem começa:

"Vou escolher uma fonte bonita."

Não.

Você precisa escolher uma fonte adequada ao produto.

Para nosso sistema podemos começar:

Inter


12px  → caption
14px  → small
16px  → body
18px  → lead
20px  → heading small
24px  → heading
30px  → heading large
36px  → display

E não basta tamanho.

Você controla:

font-family
font-size
font-weight
line-height
letter-spacing

12. Como avaliar seu próprio layout

Quero que você comece a fazer uma auditoria visual.

Pegue uma tela e faça estas perguntas:

Estrutura
[ ] Existe um objetivo claro?
[ ] Existe hierarquia?
[ ] Existe grid?
[ ] Os elementos estão alinhados?
[ ] Existe espaçamento consistente?
Tipografia
[ ] O título é claramente maior?
[ ] O texto é confortável para leitura?
[ ] Os pesos são consistentes?
[ ] Existe contraste suficiente?
Cores
[ ] Existe uma cor primária?
[ ] As cores possuem função?
[ ] Existe contraste?
[ ] Os estados estão claros?
Componentes
[ ] Botões parecem botões?
[ ] Inputs parecem inputs?
[ ] Cards possuem hierarquia?
[ ] Estados são claros?
[ ] Hover existe?
[ ] Focus existe?
[ ] Disabled existe?
[ ] Loading existe?
[ ] Empty state existe?
[ ] Error state existe?
UX
[ ] Eu sei onde estou?
[ ] Sei o que posso fazer?
[ ] Sei o que aconteceu depois de clicar?
[ ] Consigo desfazer?
[ ] Sei quando algo está carregando?
[ ] Sei quando ocorreu um erro?
Acessibilidade
[ ] Funciona com teclado?
[ ] Foco é visível?
[ ] Imagens possuem alt quando necessário?
[ ] Formulários possuem label?
[ ] Headings estão organizados?
[ ] Navegação possui landmarks?
[ ] Contraste é adequado?
[ ] Respeita redução de movimento?
