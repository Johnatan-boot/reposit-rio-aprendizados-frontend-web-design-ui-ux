🎨 Casa de Tintas — Web Design & UX/UI

Um projeto de estudo e portfólio focado em transformar fundamentos de Web Design, UX/UI, acessibilidade e Design System em uma experiência digital profissional para uma Casa de Tintas.

📌 Sobre o projeto

O Casa de Tintas é um projeto desenvolvido com o objetivo de aplicar, na prática, conceitos de:

🌐 HTML5 Semântico
🧠 UX Design
🎨 UI Design
🧩 Design System
🎯 Design Tokens
📐 Arquitetura da Informação
🧭 User Flow
📱 Responsive Design
♿ Acessibilidade
✨ Interaction Design
🔍 UX/UI Audit
🧱 Componentização
💻 HTML + CSS + JavaScript

A proposta não é simplesmente criar uma página visualmente bonita.

O objetivo é desenvolver uma interface partindo de problemas reais de usuário e objetivos de negócio, transformando essas necessidades em uma experiência digital clara, acessível, consistente e visualmente agradável.

🎯 Objetivo do produto

Uma Casa de Tintas possui diferentes tipos de clientes.

Alguns sabem exatamente o que procuram.

Outros sabem apenas:

"Quero pintar minha casa, mas não sei qual tinta comprar."

Por isso, a experiência precisa ajudar o usuário desde a descoberta até a decisão.

Principais objetivos
Descobrir produtos
       ↓
Explorar categorias
       ↓
Encontrar cores
       ↓
Buscar inspiração
       ↓
Comparar possibilidades
       ↓
Escolher um produto
       ↓
Comprar ou solicitar orçamento
👤 Experiência centrada no usuário

O projeto parte de uma abordagem User-Centered Design.

Antes de pensar em cores, sombras ou animações, analisamos:

O que o usuário quer?
Encontrar uma tinta.
Descobrir qual produto é adequado.
Conhecer categorias.
Encontrar cores.
Ter inspiração.
Receber ajuda.
Solicitar orçamento.
Entrar em contato com a loja.
O que o negócio quer?
Apresentar seus produtos.
Facilitar a descoberta.
Gerar interesse.
Aumentar conversões.
Receber solicitações de orçamento.
Facilitar o contato com clientes.

A interface busca equilibrar os dois lados.

♿ Acessibilidade

A acessibilidade faz parte da arquitetura do projeto desde o início.

Entre os princípios aplicados:

HTML semântico;
hierarquia correta de headings;
landmarks;
navegação por teclado;
foco visível;
aria-label quando necessário;
nomes acessíveis;
skip link;
contraste adequado;
botões semanticamente corretos;
links semanticamente corretos;
suporte a prefers-reduced-motion;
adaptação para diferentes tamanhos de tela.
Exemplo
<a
    class="skip-link"
    href="#main-content"
>
    Pular para o conteúdo principal
</a>

A intenção é permitir que usuários de teclado e tecnologias assistivas tenham acesso eficiente ao conteúdo principal.

O sistema visual é estruturado em tokens para:

Borders

Shadows

Exemplo conceitual:

:root {


    --color-primary: var(--color-dusty-olive);


    --color-background: var(--color-frozen-water);


    --space-4: 1rem;


    --radius-md: 0.5rem;


    --shadow-md: ...;


    --transition-normal: ...;


}

A vantagem é poder alterar o comportamento visual do produto sem precisar procurar valores espalhados por centenas de regras CSS.

🎨 UI Design

A linguagem visual busca combinar:

Minimalismo

Espaços amplos e baixa poluição visual.

Contraste

Proximidade

Repetição

Componentes semelhantes seguem o mesmo padrão.

Alinhamento

O conteúdo segue uma estrutura de grid.

Espaço negativo

O espaço vazio é utilizado para melhorar a leitura e hierarquia.

✨ Interaction Design

As interações devem ter propósito.

Exemplos:

hover para indicar interatividade;
foco para navegação por teclado;
transições suaves;
feedback após ações;
destaque de CTAs;
estados claros de navegação.

Animações decorativas sem função não são prioridade.

A interface deve responder às ações do usuário sem criar distração.

🎓 Objetivo de aprendizado

Este projeto faz parte de uma evolução profissional em direção ao desenvolvimento de interfaces mais completas.

O objetivo é desenvolver a capacidade de:

                 FRONTEND
                    │
        ┌───────────┼───────────┐
        │           │           │
       HTML        CSS          JS
        │           │           │

                    │
                    ▼
             ACCESSIBILITY
                    │
                    ▼
             PRODUCT THINKING

Mais do que aprender ferramentas, o projeto busca desenvolver capacidade de decisão.

💡 Princípio do projeto

Não começar pelo código visual. Começar pelo problema.

Uma interface profissional não nasce de:

"Qual cor fica bonita?"

Ela nasce de:

Quem é o usuário?
        ↓
O que ele precisa?
        ↓
Qual problema queremos resolver?
        ↓
Qual informação ele precisa?
        ↓
Qual ação queremos facilitar?
        ↓
Como organizamos essa experiência?
        ↓
Como transformamos isso em interface?

👨‍💻 Status

Em desenvolvimento 🚧

O projeto está sendo construído progressivamente, seguindo uma abordagem de UX → UI → Design System → Frontend → Acessibilidade → Auditoria.

⭐ Filosofia

Design não é decorar uma interface.

É organizar informação, reduzir esforço, comunicar intenção e ajudar pessoas a alcançar seus objetivos.
